# Laura Crawford's website

Source for the static website at <https://lcrawfo.github.io>.

The site uses GitHub Pages and Jekyll. The main pages are `index.md`, `about.md` and `blog/index.md`; site settings are in `_config.yml`. Future blog posts go in `_posts/` as Markdown files named `YYYY-MM-DD-title.md` with Jekyll front matter. The blog listing updates automatically when a post is published.
